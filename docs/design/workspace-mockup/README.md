# Mockup of the workspace (D-116)

The visual reference of the landscape workspace, drawn at the window of the phone (891 × 411 dp, 1 px = 1 dp).
The owner approved it on 2026-11-21: "Good it looks nice. I need that UX/UI."

| File | Board |
|---|---|
| `Main.dc.html` | Global bar, Playlist and Piano roll |
| `Rack.dc.html` | Playlist and Channel Rack |
| `Mixer.dc.html` | The Mixer at half size over the editing panel |
| `canvas.json` | The places of the three boards on the design canvas |

Each `.dc.html` file is a page of HTML with its own styles; a browser opens it. `ui_ux_specification.md` stays
the source of sizes and behaviour; where the mockup differs, the specification holds.

The palette of 12 colours for Tracks, Mixer channels, Patterns and Sampler instruments:
`#E8735A`, `#E0A030`, `#C9C24A`, `#6CC070`, `#3FB8A8`, `#4AA3DF`, `#6E7FE8`, `#A178E0`, `#D66BC2`, `#E0607E`,
`#9C8F7A`, `#7FA0B0`.
